Enter a season and event code (e.g. season 2025, code USGACMP). Pulls live match data from ftcscout.org and computes OPR for this event, alongside ftcscout's own published numbers, plus each team's strength of schedule.

Downloads through your browser's normal download system, straight to your Downloads folder — this file runs standalone, no Claude involved.
OPR (Pre-event) is each team's best OPR from an earlier event this season (teams with no qualifying earlier event fall back to this event's OPR, marked with *). OPR (Event) is computed from this event's matches only; OPR (current) is ftcscout's season-wide rating, which may include other events. Strength of opponents = average, across a team's matches, of the two opposing teams' combined OPR. Strength of partner = average OPR of this team's own alliance partner across those same matches. SOS = strength of opponents − strength of partner. The strength/SOS columns can use pre-event OPR, event OPR, or current OPR as the underlying rating (toggle above). Predicted record compares (own OPR + partner OPR) to the opposing alliance's combined OPR, match by match, using this event's OPR. Actual record is each team's real win-loss-tie record from the matches used above. When "Exclude surrogate matches" is checked, exclusion is per team, not per whole match: a match still counts normally for every team in it who wasn't a surrogate, even if their partner or an opponent was — it's simply skipped for the team(s) marked surrogate, for OPR, Matches, Predicted record, and Actual record alike. Click any column header to sort.
